# 🤖 Neorex AI

Neorex AI is a multi-agent AI assistant designed to help users learn, plan, and stay motivated. Instead of providing a single response, Neorex AI uses specialized AI agents to deliver structured and actionable guidance.

## 🚀 Live Demo

https://neorex-ai.onrender.com

## ✨ Features

- 📌 Planner Agent – Creates actionable plans
- 📚 Tutor Agent – Explains concepts simply
- 🔥 Motivation Agent – Provides encouragement
- 💬 Interactive chat interface
- 🌐 Deployed online with Render
- 🔒 Secure API key management using environment variables

## 🎯 Problem

Many AI assistants provide information but do not help users organize tasks, learn effectively, or stay motivated. Neorex AI addresses this by combining planning, learning, and motivation into a single experience.

## 💡 Solution

Neorex AI uses multiple AI agents with different responsibilities:

- Planner Agent
- Tutor Agent
- Motivation Agent

Each agent generates a specialized response, giving users structured guidance instead of generic answers.
